# 🤖 Blu-Rag Chatbot

**Roleplay AI with Optimized Short-Term Memory**

Blu-Rag Chatbot is a Streamlit-based roleplay application that allows you to create custom characters and chat with them using various LLM providers. It features an intelligent memory system that automatically summarizes conversations to maintain context efficiently over long interactions.

> 💡 **Note:** This project is developed by [@Blu-Rag](https://github.com/Blu-Rag)

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎭 **Custom Characters** | Define name, personality, traits, background, and speaking style |
| 🧠 **Smart Memory** | Automatic summarization when conversation exceeds threshold |
| 🔄 **Multi-Provider** | Support for Groq, Gemini, Mistral, and OpenRouter |
| 💬 **Multi-Chat** | Create and manage multiple chat sessions simultaneously |
| 🎨 **Modern UI** | Clean, responsive dark-themed interface |
| ⚡ **Streaming** | Real-time response streaming for better UX |
